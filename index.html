SuperMD 지원 / Support

한국어

시작하기

  1. 폴더 추가…로 Markdown 문서가 있는 폴더를 연결합니다. 원본 파일을 그대로 편집합니다.
  2. 사이드바에서 문서를 선택하거나 파일 열기…(⌘O)로 엽니다.
  3. 입력을 멈추면 자동 저장합니다. ⌘S로 즉시 저장하고 하단 상태를 확인할 수 있습니다.

이미지가 보이지 않아요

![설명](images/photo.png)처럼 문서 위치를 기준으로 경로를 확인하세요. 이미지가 연결된 폴더 안에 있고 파일 이름·대소문자가 일치해야 합니다. 온라인 이미지에는 인터넷 연결이 필요합니다. 이미지 삽입… 또는 Finder에서 편집 영역으로 드롭하면 문서 옆에 이미지가 복사됩니다.

문서를 전달할 때는 이미지와 함께 내보내기…를 사용해 생성된 폴더 전체를 공유하세요. Markdown 파일만 보내면 이미지가 포함되지 않습니다. 이미지 크기·정렬은 HTML img 태그와 CSS로 저장하므로 다른 Markdown 앱의 지원 여부에 따라 표시가 다를 수 있습니다.

저장에 실패했어요

하단 저장 상태와 오류 안내를 확인하세요. 복구본 보기 또는 설정 → 복구 폴더 열기에서 실제 복구 파일을 확인할 수 있습니다. 원래 폴더가 오프라인이거나 권한이 바뀌었다면 폴더를 다시 연결한 뒤 저장을 재시도하세요. 복구본은 정기 백업이나 버전 기록이 아닙니다. 해결 전에는 원본·복구본을 지우지 마세요.

폴더를 제거하면 파일도 삭제되나요?

최상위 연결 폴더의 사이드바에서 제거는 연결만 해제합니다. 내부 문서나 폴더의 휴지통으로 이동은 실제 원본 파일을 휴지통으로 이동합니다.

다른 Mac으로 문서를 옮기려면?

원본 폴더 전체 또는 이미지 포함 내보내기 폴더를 옮기고 새 Mac에서 그 폴더를 연결하세요. SuperMD 자체의 클라우드 동기화는 제공하지 않습니다.

English

Connect a folder using Add Folder…, then choose a document in the sidebar or use Open File… (Command-O). SuperMD edits the original file. Changes save automatically; Command-S saves immediately.

For missing local images, check the path relative to the document, filename capitalization and access to the containing folder. Insert or drop image files into the editor to copy them beside the document. Online images need a network connection. Use Export with Images… and share the entire generated folder to include local images.

If saving fails, inspect the status and error message. Use Show Recovery Copy or open the recovery folder in Settings. Reconnect an unavailable folder and retry saving. Do not delete original or recovery files before preserving your work. Recovery is not scheduled backup or version history.

Removing a top-level folder from the sidebar only disconnects it. Moving an internal document or folder to Trash moves the original file. To move work between Macs, transfer the complete original folder or the exported folder with images, then connect it on the other Mac. SuperMD has no built-in cloud sync.

Contact wideep98@naver.com with your app version, macOS version, reproduction steps and error message. Redact sensitive content before sharing sample files. Privacy: Privacy policy. For App Store purchase refunds, see Apple's instructions.
